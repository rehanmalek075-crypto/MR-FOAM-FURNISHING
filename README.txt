MR FOAM FURNISHING — Free static website starter

FILES
- index.html: complete responsive website, SEO title/description, product sections, contact links, WhatsApp enquiry buttons and Google Maps link.

PREVIEW
Open index.html in Chrome. Internet is needed for the stock interior photos.

PUBLISH FOR FREE (GitHub Pages)
1. Create/sign in to a GitHub account at https://github.com
2. Create a new public repository named mr-foam-furnishing
3. Upload index.html to the repository root and commit.
4. Open repository Settings → Pages.
5. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
6. Wait for GitHub Pages to publish; the public address will look like https://YOUR-USERNAME.github.io/mr-foam-furnishing/
   (replace YOUR-USERNAME with your GitHub username).

NOTES
- Free hosting can use a github.io address. A custom .in domain normally costs extra.
- Replace stock photos with your own showroom/product photos for the strongest business presentation.
- Check the contact numbers and address before publishing. Main contact button currently uses 9265530600; alternate WhatsApp is 9316693119.
- This is a static enquiry website, not an online payment/store checkout system.
